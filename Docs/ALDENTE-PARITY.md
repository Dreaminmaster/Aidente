# Aidente 与 AlDente 1.40.1 对照及 macOS 27 验证

日期：2026-11-03。上游基线：buffoons8-sketch/Aidente `9e08a5c`（6.1 / Build 21）。
本地官方应用：AlDente 1.40.1 / Build 119。目标平台按 macOS 27 理解；Aidente 没有 iOS target，不能用于 iPhone / iPad 的电池限充。

## 结论

Aidente 可以在当前 macOS 27.2（26B123）/ arm64、Xcode 27.1 环境构建并运行设置预览。
这只证明构建与用户界面兼容，不代表充电、放电、MagSafe、睡眠和所有固件均兼容。
这份 fork 尚未达到官方全部功能与视觉的完全一致，不能称为 AlDente Pro 或完整复刻。

官方 UI 的 Pro 配置被锁定，本次只读观察了可访问性标签、可见布局和公开说明；没有取得官方付费功能的可操作参考。
图标使用独立绘制和系统 SF Symbols，未复制官方图标、二进制、证书或激活机制。

## 对照

| 充电上限、巡航、手动 / 自动放电 | 已有 | 保留原有硬件策略与验证 | 需要管理员安装后实测；固件拒绝不能靠签名解决 |
| 电量依据 | 可选 macOS / 硬件电量 | 控制及主显示统一 macOS 电量，硬件电量为独立读数 | 固件边界仍使用硬件百分比；睡眠期间的边界映射未验证 |

## 本轮验证

- macOS 27.2 / arm64 / Xcode 27.1 本地构建成功，嵌套组件及 app 签名完整性验证通过。
- 原有 138 项充电、固件、睡眠策略和回滚模拟检查通过。
- 新增 21 项满电判定及校准迁移 / 阶段转换、14 项温控时间窗、13 项菜单配置检查通过；合计 186 项。
- 隔离 UI 预览正常打开；已操作验证图标样式选择和规格读数添加。
- 生产图标覆盖 0 / 5 / 50 / 79 / 100%、充电 / 接电 / 放电、明暗外观和低功耗状态的渲染检查。
- 未替换 `/Applications/AlDente.app` 或安装 Aidente，未安装后台服务、主动充放电或睡眠。

## 运行与验收

构建：`zsh BuildSupport/build_app.sh`，产物 `Dist/Aidente.app`。
隔离预览：`./script/build_and_run.sh`（也可用 Codex 的 Run Preview）。
菜单栏电气读数在缺少新鲜功率样本时显示占位符，避免将无读数误显示为零功率。

预览使用单独的偏好域 `com.aidente.app.preview`，不迁移正式偏好，不运行充电计划，不登记 / 修复 / 修改控制服务，不申请通知权限，不自动更新。
菜单栏和弹出窗口可自由试用；不要在预览中安装后台服务或启用“管理充电”。

硬件验收需用户同意后另行进行：安装独立 Aidente 应用及管理员批准的 helper，先排除与正在运行的官方 AlDente 争用，再测试达到上限、保持、拔插电、睡眠 / 唤醒和恢复默认控制。
用户的许可必须针对本次安装与测试；仓库交接文件中的其他机器历史授权不适用。
